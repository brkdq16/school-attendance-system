# School Attendance Management System

## 📌 Description
This project is a console-based application developed in C# using Object-Oriented Programming principles. It manages students, classrooms, and attendance records in an educational environment.

The system was designed to simulate a real-world problem: manual attendance tracking in schools, which is often inefficient and error-prone.

---

## 🎯 Main Features

- Manage classrooms (Create, Read, Update, Delete)
- Manage students (CRUD operations)
- Register daily attendance
- Add optional absence justification (excuses)
- View attendance by date and classroom
- Generate basic statistics (present, absent, gender distribution)
- Persistent storage using JSON files

---

## 🧠 Technologies Used

- C#
- .NET
- Object-Oriented Programming (OOP)
- JSON for data persistence
- Console Application

---

## 🏗️ Architecture

The project follows a simple layered architecture:

- Models: Entities and enums
- Services: Business logic
- UI: Console menus
- Data: JSON storage handling
